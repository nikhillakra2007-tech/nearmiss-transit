New/edited backend code: no `eval(`/`exec(`/`subprocess`/`shell=True`,
no hardcoded secrets or keys, no URLs, no dynamic SQL (ORM filters
only), user ranges strictly capped (lookback 1..180, step >= 5;
FastAPI-typed ints auto-422). Clean.

## Safety-language sweep

Replay payload + `replay.py`: none of will fail / guarantee(d) / unsafe /
dangerous / accident / cause(d) / caused by / prediction certainty /
predicted failure. Note: pre-existing repo copy ("not a guaranteed
prediction" in the older forecast card; ban-terms listed inside
`safety.py`/`explain.py` ban lists) is intentionally untouched — the
sweep test is scoped to the feature's new output to avoid false
positives on pre-existing honest wording and on the ban lists
themselves.
